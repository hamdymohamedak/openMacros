# AK-Macros

Script-like Rust macros for clean automation and readable orchestration.

AK-Macros provides a focused macro API for:

- CLI and terminal automation
- Filesystem operations
- String and number helpers
- Lightweight flow control for repetitive tasks

## Why AK-Macros

- Predictable naming and signatures
- Small and composable macro surface
- Unified error model for fallible operations
- Project structure ready for long-term maintenance
